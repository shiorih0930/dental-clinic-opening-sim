# 歯科医院開業シミュレーション

歯科医師として開業（新規・居抜き・親族承継・第三者承継・M&A）し、最初の3か月（90日）を経営するシミュレーションゲームです。
単一の HTML ファイル（`index.html`）で動きます。ビルドは不要です。

## 内容
- 開院の形・貯金・立地（全国47都道府県）・スタッフ・機器がランダムに決まります（開設数や最低賃金などの統計にもとづく）
- 1日＝1秒で時間が進み、スタッフ・機器・患者さんの出来事、クレーム対応の会話が起きます
- 月末に決算と、スタッフからの360度評価を確認できます
- Doctorbook academy の動画、HandsON School などの学びのイベント

## 使い方
`index.html` をブラウザで開きます。クレーム対応の会話（AI患者役）は、Claude のアーティファクト上で動かしたときに使えます。

## 注意
- 金額・効果・比率の多くは、ゲーム内の仮の設定です。
- 外部サービス（Doctorbook academy など）の内容は、公開ページで確認できた範囲です。
